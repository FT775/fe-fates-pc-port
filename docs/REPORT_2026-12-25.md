# Round 51 report: the Randomizer page inside the game (F-044)

**Is it ready?** Yes, it is ready for you to look at. Nobody has seen it in a window yet; that part is yours. Nothing counts as done until you say ok.

**How to try it**
1. Double-click PLAY.bat, as usual.
2. On the title screen choose **New Game** on an empty file.
3. Pick the difficulty (Normal / Hard / Lunatic).
4. Pick **Casual** or **Classic**. The game pauses and the **Randomizer** page opens over it.
5. Switch **Randomizer** on, type a seed or press **Random**, and set the rows (or press **Everything on**).
6. Press **Start game**. It says "Making the game from seed X" for a few seconds, then goes on to the avatar screen.

With Randomizer off, Start game plays the original game, unchanged. In a game, Esc, then **Randomizer**, shows **This run**: the seed, the settings that are not at their default, and the spoiler log.

**What each row does**
- **Randomizer:** off = the original game; on = a game made from the seed.
- **Seed:** the same seed and the same rows always give the same game. Empty = a new seed is made and shown.
- **Classes:** each playable unit gets a new class it is allowed to have.
- **Growths:** new growth rates.
- **Join stats:** new starting stats.
- **Class trees:** "own" keeps each unit's class family; "any" allows any class.
- **Royals keep their classes:** the royal units keep their own classes.
- **Children:** greyed out, not built.
- **Growths mode, variance, min, max, Adjust HP growths:** how far growths are changed, and their limits.
- **Bases mode, Base variance, Scale to join level:** how starting stats are changed.
- **Personal skills:** keep, shuffle among units, or random.
- **Skill slots:** keep, follow the new class, or random.
- **Starting items:** new starting weapons and items.
- **Shops** and **Shop sides:** new shop stock, from your side's items or mixed.
- **Castle rewards:** new castle rewards.
- **Enemy weapons, Enemy classes, Boss classes, Enemy class trees:** new enemy gear and classes.
- **Everything on:** the suggested values for all rows. **Defaults:** back to the start values.

**What the robot proved** (no window, recorded play only, all PASS)
- **T2:** a randomized new game with every row on is the same as that seed installed as a mod. The tables and all 30 units in the Prologue match, with 0 differences.
- **T4:** with Randomizer off, the new program is exactly the old one: the same memory and the same save files.
- **T5:** a randomized save keeps its seed when loaded, even after browsing the Load list. An original save stays original. The robot also found two bugs here and they are fixed: a wrong warning at every boot, and one kind of early save that lost its randomizer when loaded.
- **T6:** a battle save comes back randomized, including that chapter's enemy placements.
