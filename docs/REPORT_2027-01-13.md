## How to make a release
- **RELEASE.bat**: double-click it. It builds nothing.
- **RELEASE WITH ENGINE BUILD.bat**: also builds the game parts that are out of date. Its first screen lists every build and its counted time. Pressing Enter is your OK for those builds. Type N and Enter to stop.
- Both windows say "Finished" or "Stopped" at the end and wait for a key.
- Read docs/RELEASE.md for the details.
- **Today a plain RELEASE.bat stops at the first check.** The capture library is out of date: round 40 changed two menu files after the library was built. This is real, not a tool mistake. It needs a rebuild, and the rebuild needs your OK.

## What the screens say
1. **Header**: what will run, with a counted time for each step. "ENGINE BUILD: NO" for a normal release.
2. **Checks**: you are on master, nothing is uncommitted, nothing is running, the disk has enough free space, the ROM and test files are unchanged, and the tag is free.
3. **"FULL is due"**: you are asked Y/N to go on with the CORE test only. It is due now, because this is the first release.
4. Core tests, smoke, package (11 safety gates), then the record and the local tag.
5. **Last screen**: "Ready. Core passed. Not pushed." It also shows the notes, what was skipped, counted vs actual times, the undo line and the push command.
- If any step fails, the release stops and prints one plain line saying what to do.

## Safety
- **Backup first.** An engine release backs up the exe, its records, game-path.txt, boot-server and the capture library to build/backup/ before it installs anything.
- **Automatic undo.** If any check fails after installing, the old files go back and are checked again. Backups are never deleted.
- **It never pushes.** Only you push, with `release.py push r68`. Push is refused in agent sessions. You type the tag back to confirm.
- **Privacy scan.** It looks for your user name, home folder, repo path and e-mail in every file, the history and the notes. It shows them masked (for example "F***"). A finding in the current files stops the package.
