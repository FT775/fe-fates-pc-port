# What polish means

**For the owner.** Polish is the last 5% in the plan, and it is not defined there. It is not more game. It is the point where a player who is not us can start the game, change a word, and put it back, without reading the round notes.

Status 2026-11-18. Read: `docs/PORT_PLAN.md` (step 11 is "not started"), `docs/CAPABILITY.md`, `docs/EXTRAS.md`, `docs/LOOK_SITTING.md`, `docs/tracks/MODDING_GUIDE_DRAFT.md`. The front door is already done: the shortcut starts the game, and you have played it. Polish does not rebuild that.

## Finished, for a player

1. **Install.** The shortcut starts the game. If something it needs is missing, it stops and says so. It does not start a half game.
2. **Launch.** The game reaches a title, and a save of yours loads. No mod is in.
3. **Saves.** Your saves are not the test saves. A mod does not write into them unless you save while it is in. Uninstall puts the game's files back.
4. **Mods folder.** A folder under `mods/`, turned on, built, and taken out, with a one-page guide. Words, number tables, one face, and the battle-draw switches are the changes that exist today.
5. **Options page.** Either it changes the game, or the page says it does not. Today it writes a file nothing reads. Shipping it as if it worked is not finished.
6. **Performance.** No new speed target. A known-issues line if a long play needs free disk. The 60 fps battle switch stays off until you turn it on. The story-scene speed switch stays off. It changes the hidden dice.
7. **Known issues.** One page, in plain words, of what is not done and what can hurt a save.
8. **Docs.** The player page matches what the tools actually do. A line nobody has seen in a window stays marked not yet checked.

| 4 | The modding draft becomes the player page, after the look. Lines you did not see stay marked | Claude | Half a day [low] |
| 5 | The options page says "this does not change the game yet," or it is not on the screen a player opens. Hooking it is a different yes | You say which. Claude does the label | A few hours [low] |
| 6 | You start once with no mod, and once after uninstall, and the game is the original | You | 10 minutes |

Polish does not start until the look, or the player page would describe a window nobody has seen.
