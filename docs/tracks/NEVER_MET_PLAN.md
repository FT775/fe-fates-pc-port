# The 34 readers real play never meets

**For the owner.** These are checks the game can make, that none of our real chapters has made yet. Playing Conquest and Revelation further is not the way to light them up. Most of them need a child, a download item, a cannon we fire, or a menu nobody has found. The cheap answer is the test we already have on the computer. A poke does not count as real play.

Status 2026-11-17. Read: `docs/REPORT_2026-11-30.md` (229 of 263 met, the same 34 never met), `docs/harness/H56.md`, `docs/PORT_PLAN.md` (the round-11 list of 29), `docs/CHEATS.md`, `docs/ITEM.md`, `docs/CAPABILITY.md`. The reports do not reprint all 34 names. The notes name 31. Three are only in the count. Those three are not guessed here.

A chapter already running (Conquest 16–27, Revelation 21–27) is a free meet only if the robot was going to do that thing anyway. It is not a reason to capture, marry, or open a menu. F-025: do not play for coverage. F-019: a labeled poke is not real play.

## Ranked by cost

1. **Leave them on the host test.** No chapter, no poke. This is the right end for almost all of them.
2. **Two screens we already open.** One shop visit that buys more than one of an item. One status screen with the help text open. If the reader is still absent, stop. Do not add a route.
3. **Already poked.** Do not poke those again. They stay off the real-play count.
4. **One new poke, only if a live record is required and the host test is not enough.** Still not real play. One existing route, labeled.
5. **Do not spend a chapter.** The maps in progress are not a plan for this list.

## What this list does not do

It does not send the robot into a child paralogue, a download, or a castle menu. It does not treat a cheat as real play. It does not add Conquest 20 or Revelation 25 in order to meet a reader. If one of the 34 shows up in a chapter that was going to be played anyway, keep that recording and strike the name. Do not go looking.

The three unnamed ones stay unnamed until a note prints them. A script that marks all 34 "not needed" is not this plan. The host test is the evidence. A live miss is not a failure of the chapter.
