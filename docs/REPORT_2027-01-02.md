# Round 59: the shuffle, music, enemy levels and tougher bosses on the page; recolour; fast start; Seal save fix

Status: built and checked by the robot. Nothing is committed. Nothing counts as done until you say ok (F-037). This report follows the evidence and the reviewers' corrections, not the robot's first claims.

## What is new on the in-game Randomizer page
- **Character shuffle, "keep the face" look.** A join spot keeps its face and name, but the unit plays as someone else, with that person's class, stats, growths and skills. It works on all four paths, Seal of Flames included. Example: at Birthright chapter 4, Rinkah joins as a Spear Fighter with HP 22 (off: Oni Savage, HP 20).
- **Random music** (map and battle themes), **Enemy levels up** and **Tougher bosses** are no longer grey.
- **Recolour.** With the shuffle on, a swapped unit's battle hair colour (and its face-data colour) becomes the new person's. A unit in a class it never had keeps its own hair and skin. The army outfit stays, so you can still tell the sides apart (Grok's rule). Recolour is always on with the shuffle; there is no Recolour row yet.
- **Faster start.** The page makes your game in the background while you look at it. Any change to a row throws that guess away and starts again. Start game uses exactly the page's values, and nothing is applied before you press it.

## Start time (measured)
- With everything on and the background make already finished, the time from the mode pick to "laid" was **9-16 ms for Fates and 110-141 ms for Seal of Flames** (3 runs each, headless at real game speed).
- After that, the game reaches the avatar screen in the same frames as with the randomizer off. So the start is under 2 s **when the background make has finished**.
- **Not under 2 s if you change rows and press Start game at once.** Then you wait for the rest of the make, about 2-8 s, shown as "Making your game... N%". The first Seal make with an empty cache took 8.3 s.
- Correction: these are log times from headless runs. No robot drove the real page and timed Start game to the avatar screen.
- **Your rule** (guesses thrown away, Start game uses exactly the page's values) was tested headless. A finished guess was replaced at frame 2500, its folders were deleted, and the laid game was byte-identical to a fresh make of the final values. No robot changed rows on the real page.

## Per path: what broke (and was fixed), what passed
Every chapter was checked with the randomizer off and with 3 seeds that have everything on (all1, all2, all3). Each check covers preparations or the map, the enemy phase, a battle save, the reload, and a memory readback of every patched cell.

Found and fixed this round:
1. **Seal of Flames save/reload**, which failed even with the randomizer off. The mod copied 41 chapter person files and kept the old chapter's name inside them, so a reload loaded the wrong chapter's people. Fixed in the engine (patch 0018). The mod on disk is not changed.
2. **Patched chapter files overwrote their own end** while the game unpacked them. Fixed in patch 0017. This was also the cause of round 58's wrong labels.
3. **The Seal fix made the renamed files too small.** 16 Seal chapters kept their original person file, so boss stats, enemy levels and music were not applied there. Fixed in patch 0021 (the check's rebuild).
