# Report 2026-12-23: the randomizer's playable set is put together (round 49, F-043)

**What the randomizer does now.** With one seed it can now change these things:
- **Slice 1, as before:** each person's class, growths and join stats.
- **Stats:** the FE8 port's growth modes (Redistribute, Delta, Full, with variance, min, max and Adjust HP) and base modes (Redistribute, Delta, with base variance).
- **Skills:** personal skills (keep, shuffle or random) and the skills people join with (keep, follow the new class, or random).
- **Items:** starting items, what the four castle shops sell (prices stay the same) and the castle battle and visit rewards.
- **Enemies:** enemy weapons, and if you switch them on, enemy and boss classes. A new class must still be able to get around the map. Story units and Conquest 9 and 16, Revelation 8 and 13 are never changed.

Everything new is **off unless you turn it on**. With it all off you get exactly the same game as before, so old seeds don't change. The same seed and the same options always give the same game. Switching one part on or off never changes what another part gives.

**How to pick the options.** Double-click PLAY RANDOMIZED.bat and type 1. Give a seed (or press Enter for a new one) and answer the three switches (Classes, Growths, Join stats). Then comes "More options":
- **Enter:** nothing more changes.
- **a:** everything on, with the suggested values (Growths and Bases Redistribute, personal skills shuffled, class skills follow the new class, starting items, shops, castle rewards, enemy weapons, enemy and boss classes).
- **c:** go through each row; Enter keeps that row's default.

The list of your randomized games shows which options each one has on.

**What the robot saw.** It used one test seed with every option on, in its own test game, with no window. It started from the Chapter 1 clear save, replayed the recorded Chapter 2 presses (no new play), and read the game's memory on the Chapter 2 map:
- All 49 people's classes, stats, growths, weapon ranks and skills were exactly what the plan says.
- All shop stock and castle rewards were exactly what the plan says.
- Gunter's and Felicia's items and skills were right.
- All 4 enemies were right: 2 of them had a new class and weapon, and every enemy could use its weapon.
- Then the mod was removed (0 files left), and the same run showed the original game.

0 mismatches.
