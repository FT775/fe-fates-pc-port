# Round 81 options rows (Grok consult)

**For the owner.** One question to Grok about the new rows that set some of the game's own Options for you at
every New Game. Grok agreed with almost all of the plan, renamed the line, and said to keep the danger zone out
for now.

Asked 2026-11-25 21:20 EST, answered 21:21 (counted, `date`), from round 81's desk part. The question:
build/r81/plan/GROK_QUERY.md (facts only, no game data, no private details). Grok's answer, word for word:
build/r81/plan/grok_answer.txt. What follows is a summary in our words.

## What Grok said

- **Which rows.** Players set battle animations and map speed once and forget them. Many also set the enemy
  turn to Move or All on a second playthrough. HP bars are usually left on, but the row does no harm. Nothing
  else on the game's Options screen is a habit players have. The danger zone is something you toggle with a
  button during the map, not a New Game choice.
- **The line's name.** "New Game defaults", not "For every New Game": the second one sounds as if it changes the
  game you are playing right now. Closed, the line shows "game's choice" or "2 set". Row labels as we proposed:
  Battle animations, Map speed, Enemy turn skip, HP bars. The first choice of each row: Game's choice.
- **The default.** "Game's choice" on every row. A row that started on Fast would change a game the player never
  asked to change.
- **Enemy turn skip.** It belongs here. The port's own 2x / 4x was cut, and this is the game's own line. Leaving
  it out would mean the one skip people want is the one this heading does not offer.
- **Battle animations, the side effect.** Grok's wording: "Off plays fights on the map. Supports and dances
  follow this too."
- **Danger zone.** Leave it out until someone has seen what its three values change. Offering it now would be a
  switch with no meaning.
- **One sentence for the report.** Roughly: New Game defaults sets a few of the game's own options once, when you
  pick your mode for a New Game, and a game already started is left alone. (Grok named Casual and Classic; the
  report names all three modes, since Phoenix starts a New Game the same way.)

## The calls this settles (plan defaults in docs/ROUND81_PLAN.md, "Your calls")

| Call | Settled as |
|---|---|
| Rows offered | four: Battle animations (Off / On), Map speed (Normal / Fast / Fast while A is held), Enemy turn skip (Off / Move / All), HP bars (Off / On) |
| Danger zone | **not offered** in round 81 (the home part, the options trace and Grok agree) |
| Name of the closed line | **New Game defaults** |
| Default of every row | **Game's choice** (the port does nothing, not even watch) |
| Enemy turn skip as a row | **yes**; round 80's help line is reworded to point at the new row as well as the game's line 6 and the Start key |
| Battle animations help | "Off plays fights on the map. Supports and dances follow this too." |
| The note under the rows | kept from the plan: used when you start a New Game; a game already going keeps its own settings (change those on the game's Options screen) |

Not asked of Grok and not changed by it: the timing sentence ("later enemy moves can differ; hits, damage and
the battle dice stay the same"), which comes from round 80's measured E1 result, and the hook design (one write
per New Game, never at a load, never the versus copy).
