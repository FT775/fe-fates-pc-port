# Boss classes on Fates: Grok's view (round 61, cells track)

Asked by the cells track on 2026-11-21 (facts only, no game data).

## Question

Round 61, cells track (Fire Emblem Fates PC port randomizer). A player-facing design question, facts only, no game data.

Finding: the page row "Boss classes" (randomize the class of enemy bosses) changes almost nothing on the three Fates routes. Of the boss placements in the main story, nearly all are skipped on purpose by the randomizer: about 106 are "story versions of a named person" (the boss is a character who appears elsewhere as a named person, e.g. a royal or retainer met again later), about 60 are bosses that the chapter's event script names (they talk, die with lines, or the script moves them), 10 are in guarded chapters, and about 8 have no class that keeps the same weapon kind and rank. In all of Fates only 4 paralogue bosses (Paralogues 2, 13, 15 and 17, generic "Invader"-style bosses) can change, and with a given seed often only one of them does. On Seal of Flames (a fan story mod) 7 boss rows change (for example a Wyvern Lord boss becomes a Malig Knight). The robot proved it works where it applies (same seed, boss class the only change).

Options:
 A) keep the rule as is, and say it on the page: "Boss classes: only bosses with no story role change (on Fates: a few paralogue bosses)", maybe grey the row out on Fates.
 B) widen it to the "story versions of a named person" when the script does not name them (risk: a known character shows up in a class that does not match their portrait, story dialogue or later recruit class; their weapons must change with the class).
 C) widen it further to script-named bosses too (risk: event scenes that check or animate the class, more story mismatch).

Which would fans of Fates randomizers expect, and what would you pick for the page text? Keep it short: a pick, one line of page help text, and any fan-convention note. Say if this should be the owner's call.

## Grok's answer

Fans of the public Fates randomizers expect bosses to change class. Ignis sells that as part of the point. A row that only moves one paralogue boss will look broken to them. That is a story choice, so it is the owner's call.

I would ship **A**. Widening to named people puts a known face in a class that does not match the portrait or the class they join as later. Widening to script-named bosses can break a scene that moves or kills that person.

The page line should say: "Boss classes: only bosses with no story role. On Fates, a few paralogue bosses. Named characters stay as the story made them."
