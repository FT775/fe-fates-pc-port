# Are we working smart?

**For the owner.** No. The game already runs. The rounds are spending hours replaying every chapter to prove a page, and the proof can still be the wrong number. A player does not need 536 runs to know a sword hits harder. They need one fight, on the program they will play, with the number they can see.

Status 2026-11-22. Read: the January reports, `docs/collab/ON_TRACK_GROK.md`, `docs/collab/SPEED_AGREED.md`.

## The waste

The everything-on check is the waste. Four paths, four settings, every chapter, about 536 runs, about 3.5 hours, and it still passed "boss weapon +1" by counting forge marks while the might was 1 short. That is a check that costs a half day and does not see the screen.

Engine builds are the second waste when they wait on a help line. The words already come from a Python list. A sentence that overflows does not need a new program. A new picture, a new button, or a rule the game must enforce does.

The third waste is asking the same taste question in every report. Most of those calls already have a pick. Asking again spends your time and mine, and the round waits.

## The picks

1. **Change-scoped.** A round checks the rows it touched, plus one short smoke: one chapter on each path, randomizer off, and one everything-on seed. The full matrix runs only before you play, or every third round, whichever comes first. Cut the 536-run pass from ordinary rounds.

2. **The judge reads the number you would see.** Might is might, not a forge count. A judge that uses a stand-in fails the round. Each new feature gets one looked-at pair on the final program, same unit, same spot. Robot and memory are extra, not a substitute.

3. **Page words stay in the Python list.** No engine build for a label, a help line, or a greyed row. Batch engine work into fewer, bigger rounds: a picture, a button, or a rule the game must store. A 4.5 second start is a later engine round, not a reason to hold a text fix.

4. **Default to the written pick.** Ask you only when two honest choices change how the game feels, and the notes do not already say which. Do not ask again about a pick that is already in a decision.

5. **We are polishing the randomizer past the game you can play.** Fans need class, growth, items, and who joins, visible on one seed. They do not need every boss proved, a Seal boss list, and a recolour pass before you start. The shortest path is: fix the might number, smoke-check, you start one Birthright or Conquest seed and play. Seal waits if its code patch does not apply.

6. **Trim round 63.** Keep the might fix. Prove three bosses, not 24. Drop the Seal boss list and the Conquest recolour from this round. The drop flag only if drops are on. The save-slot read after the might fix, not beside it.

7. **Stop these.** A new decision file for a one-line call. A coverage replay that relaunches itself. An engine build for help text. Asking for a design pick that a note already made.

You can play a seed after the might fix and one smoke check. The rest of the matrix is for the week you sit down to play, not for every round.
