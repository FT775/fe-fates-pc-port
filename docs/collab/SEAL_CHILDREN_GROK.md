# Children in Seal of Flames

**For the owner.** Seal of Flames does not advertise children. The public page says 52 new people, made from the game's generic faces, and that supports are not finished. Grey the Children row. Do not hide it, and do not edit a child row the author left in a chapter.

Status 2026-11-20. Public pages only. The mod was not downloaded.

Sources: [Seal of Flames](https://gamebanana.com/mods/656034) (52 new characters, supports incomplete, no custom assets, other mods not meant to be used with it). The changelog page did not return the mod's notes. The trailer does not name children. [Binding Blade chapters](https://fireemblemwiki.org/wiki/List_of_chapters_in_Fire_Emblem:_The_Binding_Blade) lists the side maps 8x, 12x, 14x, 16x, 20x, and 21x. The mod page does not say those maps were put in the Fates child slots.

## The picks

1. **No public children.** The page does not mention a child, a child map, or a marriage. Supports are listed as unfinished. It does not say which Fates slots its side chapters use. I will not guess that an X file is a Binding Blade gaiden.

2. **Grey it, with the line "Seal of Flames has no children."** Hiding the row makes the page jump. Leaving it on edits files no chapter uses, which looks like a broken switch. A missing option should stay visible and say why.

3. **If a child row still stands on a Seal map, leave it.** The author put that person there. The Children switch is for a child who joins from parents. It is not a licence to repaint a leftover.

4. **Do not treat Binding Blade recruits as children.** Sibling pairs and side-chapter recruits are ordinary joins. If they should change, that is the recruit shuffle, not this row.

The host check, if it finds a real child join, is the only thing that would reopen this. Until that result is in a note, the row stays grey.
