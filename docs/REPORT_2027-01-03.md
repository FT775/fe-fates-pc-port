## Seal of Flames battle save/reload
- **Cause:** three of the mod's 44 person files (R021, R023, Y004) number their people out of order.
  - A battle save stores a unit's person as a number, and the reload looks that number up by position, so a different person came back.
  - Every changed unit matches this mapping.
  - It was not the mod's known mid-battle-save limit, and it was not our compare.
- **Fix:** patch 0022 renumbers such a file in file order, in memory only. The mod on disk is never changed.
- **Result:** all 41 Seal chapters reload with equal units, with the randomizer off and with all three seeds.
- **Not a mismatch:** in R021 one enemy (an Outlaw) is in a different place in the chapter-start read than after the reload. The save and the reload match. It most likely moved in the enemy phase before the save (not proven).
- **Old saves:** battle saves made in R021, R023 or Y004 before this fix still reload the wrong people. New saves are right.
