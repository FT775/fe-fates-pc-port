## 1. Tougher bosses: weapon might
**What was wrong.** Round 62 added forge levels to boss weapons. For enemies and bosses the game uses a forge row where one level adds only +1 might, so the screen showed +1 / +1 / +2 instead of +1 / +2 / +3.

**What changed.** The randomizer now picks the forge row the game will really use. It forges until the shown might is +1 / +2 / +3, stopping at the game's forge maximum of 7. The spoiler says "might +N shown", and it says so when the maximum stops the climb (no boss needed that note).
