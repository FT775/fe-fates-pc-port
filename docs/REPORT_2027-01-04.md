## Nuzlocke on every path
- **Cause of the Birthright failure:** the byte the round-60 core waited for is the map camera angle option. Every robot save has the default angle, so on Birthright the core never acted.
- **Fix:** the new gate is "a player army exists". This works on every path and save.
- A fallen unit in a battle save is moved out of the army before the map can draw it.

Results on the final build:
- **All 4 paths pass**, including bt-ch9-clear:
  - A castle load with two people in the graveyard puts both among the fallen and switches Casual to Classic.
  - At a chapter start, the fallen are on no army list and not on the map.
- A real death is written to the graveyard with the turn and the name: "Kaze: A007, turn 14". Kaze stays fallen after a state load, a fresh program start and at the start of chapter 7.
- **Battle save:** the fallen are never in the army.
- **A brand-new Nuzlocke game from the New Game mode pick:** pass.
- **PLAY RANDOMIZED now accepts Nuzlocke:** pass. "First recruit per chapter" is still refused.
- **Revelation's "Felicia drawn on the map now" line is explained.** At a chapter start, the game itself briefly takes a fallen person back if that chapter's placement names them. She is now moved straight back, and the line is gone.
- **Caveats:**
  - The turn number has not been compared with the game's own turn display.
  - The Seal graveyard shows no names until the Seal run is made again.
  - A fallen unit inside a Zakuro save state (not a game save) is removed only once its map actor goes.
  - Real enemy-phase deaths now count, so a long Nuzlocke check loses units for real.

Steps:
1. Copy them back over play/game/Fire Emblem Fates.exe, play/game/build-record.json and engine/target/zakuro-server/release/boot-server.exe.
2. For the engine sources, move patches 0025 and 0026 out of patches/zakuro and run `python tools/engine/engine.py apply --force`.
3. For the server source and the randomizer tool changes (the audio command, skills.py, enemies.py, tracks.py, nuzlocke.py, rando.py): `git revert` the round 61 commit.

With the randomizer off, the game is memory-identical either way.
