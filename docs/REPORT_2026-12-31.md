# Randomizer round W1: new rows on the in-game Randomizer page

Status: built and checked by the robot. Nothing is committed, and it does not count as done until you say ok.

## New rows you will see (all off by default; off changes nothing)
- **Spread classes evenly**: fewer units end up in the same class.
- **Random promotions**: each class gets new Master Seal choices.
  - Promotions stay on own side: the new choices are only classes from the unit's own side (Hoshido or Nohr).
- **Heart Seal classes**: each unit gets a random second class instead of its usual one.
- **Children**: the children get a random class, growths and one skill. Who their parents are does not change. (This row used to be grey and marked "not built".)
- **Class growth rates / How much**: shifts each class's growth rates up or down, in steps of 5.
- **Class base stats / How much**: shifts each class's base stats up or down by a small amount.
- **Class movement**: classes may move 1 or 2 squares more or fewer. In practice they mostly get faster, and no enemy gets stuck.
- **Weapon stats**: changes each weapon's might, hit, crit, avoid and staff uses.
- **Weapon special powers / Wild powers too**: some weapons get a special power such as brave or double counter. You see them only in the spoiler.
- **Stronger enemy weapons (chance)**: some enemies carry a better weapon of the same kind. They never lose a bonus against a unit type, such as dragons.
- **Enemies grow faster / Extra growth %**: enemies get higher growths, either the same all game or more later in the story. Allied guest units get them too.
- **Enemies drop items (chance)**: some enemies drop their item when beaten (set in steps of 5%).
