## Overnight round 5 (night of 2026-11-12 to 2026-11-13)

### In plain words (ELI5)

Think of the game as a huge recipe book written in a language only the 3DS reads. We are
rewriting recipes into plain language, one at a time, and a robot plays the game to check that
each rewritten recipe gives exactly the same dish as the original.

Last night three things happened:

1. **The robot played further.** It beat Chapter 9 (a maze map with 17 enemies plus
   reinforcements, 19 turns). Azura sang five times, and one of her songs gave her a level.
2. **The robot forged a weapon.** After the chapter it used the new Dragon Vein point to build a
   Lottery Shop. Its free daily draw gave one Coral (the ore for naginatas). The robot bought a
   second Iron Naginata for Subaki and the Smithy fused the two: **Iron Naginata +1, Might 6 -> 8**.
   The game's memory shows the +1 weapon, and it is still there after loading the save.
3. **The skill checks are readable.** "Does this unit have skill X?", the skill's chance to fire,
   and the order in which a fight picks an attack skill (Lethality, Aether, Astra, ... Vengeance)
   are now written in plain C and explained in docs/SKILLS.md. One fact for later options: the game
   rolls a 100-sided die for each attack skill *before* it looks at the chance, so carrying a skill
   changes every later die in that fight.

Then the join step did the real-play check: it rebuilt the checker once and let the robot replay
**all 14 Birthright pieces** (the 12 from yesterday plus the two new Chapter 9 pieces) with the
game's code and the readable code side by side.
