## The clock and the random numbers

- Readable pieces answer in PC code and use no game-processor time, so the game's clock runs a tiny bit slower.
- **No dice seed moved.**
  - The three clock reads that seed the random number generators are identical in every mode.
  - All 52 (bt-ch9) and 57 (bt-ch9-ore) generator seeds are identical, from the same callers.
  - The first 4,967 random numbers are identical.
- **One thing does move.** From number 4,968 on, readable mode takes numbers from the game's one shared generator in a slightly different order: one extra draw, then the same numbers shifted.
  - That generator feeds sound-effect variation, per-frame tasks and kaneko::frnd.
  - On these routes it changed no save byte except the clock, and both routes played the same.
  - The separately seeded generators (AI, level-ups, map) drew 550 of the first 20,000 numbers, and all 550 matched one for one.
  - This was not checked on other routes. In principle it could reach a gameplay draw from the shared generator.
  - A real fix is to charge game-processor time in readable mode. That is an engine decision for you.
- Shadow mode moves nothing: every clock read and every random number is the same as the original game.
