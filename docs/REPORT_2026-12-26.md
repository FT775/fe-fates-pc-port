# Report 2026-12-26: Seal of Flames as your own optional path (round 52)

Credit: **Seal of Flames by Laz14 (gamebanana.com/mods/656034)**, CC BY-NC-ND 4.0. It is installed only on your machine, from your own download, unchanged. It is not distributed: no file of the mod is in git.

**How to play it.** Double-click **PLAY SEAL OF FLAMES.bat** in the port folder. The first start unpacks your download (`Seal of Flames v6\0004000000179800.zip`) into `play\seal-of-flames\`. That is already done (979 files, checked by hash). Then it starts the same program as PLAY.bat, with its own folder. `PLAY SEAL OF FLAMES.bat --dry-run` checks everything and starts nothing. `status` shows where its saves are.

**Separate saves.** Seal of Flames has its own saves, settings, save states and mods folder, all inside `play\seal-of-flames\`. Your normal game, its saves, its settings and `%APPDATA%\zakuro` are never read or changed by it. Settings start from the port's defaults the first time, so set your keys and window there once. To start Seal of Flames from a normal save, use `--import-save <a backup zip>`. It copies one way and only works while Seal of Flames has no save yet.

**What the robot proved** (headless, on recordings we already had, on copies under build/):
- The mod loads: 222 game files replaced, 756 added. Its small code patch is applied, and the program runs that one changed function the slow, exact way. The game knows 163 chapters (the normal game has 122).
- A new game starts and runs. Chapter 6 opens on the mod's own map. Saves load back correctly.
- A unit test shows the patched function finds all of the mod's later chapters (numbers 128 to 162).
- The normal game is byte-for-byte unchanged. None of your normal folders changed.
- The Randomizer is refused cleanly in this profile, and the game goes on as Seal of Flames.

**What only you can check.**
- The real program with the mod. The robot used the same core, but the round rules kept it from starting Fire Emblem Fates.exe.
- Playing into the mod's later chapters (number 128 and up), with a save and a reload there. No recording reaches them.
- How the mod plays and looks in general.

**What doesn't work.**
- The in-game Randomizer is greyed out here. It says "Randomizer is for the original game; not available with Seal of Flames". If you press its "Play the original game" button, that means Seal of Flames without the randomizer.
- The mod's own known issues stay: bookmarks and mid-battle saves do not load, the Private Quarters crash and the accessory shop. Save normally between chapters and use save states too.

**How to remove it.** Delete the folder `play\seal-of-flames\`. That removes the mod copy and its saves, so copy `play\seal-of-flames\data\` first if you want to keep them. Your normal game is not affected. `Seal of Flames v6\` is your own download. We never change it, and you can delete it too (PLAY SEAL OF FLAMES.bat then says the zip was not found and starts nothing).
