## What a new randomized game now promises
Every new randomized game now checks three things. If a seed would miss one, the randomizer quietly fixes it.

| Story | Healer holding a staff, by | Lock opener, by | Flier, by |

- **Dragon vein:** always met, because Corrin always has it.
- **How the fix works:** one person from the free pool gets a class that fills the missing role. Kept people (Corrin, Azura, the royals) and held people (Nyx, Shura) are never changed. Felicia and Jakob count as one slot.
- **No repeated class:** the fix first picks a role class nobody else in that chapter's army already has. Pairs of classes count as one. It uses a taken class only when no free one is left. In the real-data sweeps, no fix ever needed a repeated class.
- **Staff in hand:** a repaired healer always holds a staff. If their join spot has none, the cheapest ordinary staff is added.
- **The spoiler:** a new "Guarantees" section shows every need and every fix.
- **The fix never breaks an earlier need.** It checks again after each fix, at most 3 times. Every later step that changes classes or skills is checked again too.
