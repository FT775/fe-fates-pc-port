## Small things to know
- Randomize everything writes a long list in the help line (four lines at 800x960). Moving the pointer to another row puts that row's help back.
- With Spoiler log off, spoiler.txt is deleted, but plan.json (the same information in machine form) stays beside the run because `rando.py check` needs it. Say if you want that hidden too.
- Help follows the mouse pointer or keyboard focus.

## How to undo
Copy build/backup/Fire Emblem Fates.exe.2026-11-21-pre-r62b and build-record.json.2026-11-21-pre-r62b back into play/game/ (drop the date suffix). Remove patches/zakuro/0030-*.patch and run `python tools/engine/engine.py apply` (or keep the patch; the exe alone decides what you play). The randomizer tools keep reading old answers, so old saved settings still work.
