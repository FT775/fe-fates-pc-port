## What moved where

## What a new downloader does now
1. Put the Fire Emblem Fates Special Edition (USA) .cci in `roms/` (roms/README.txt says so). Any file name works.
2. For Seal of Flames: put the GameBanana download zip in `roms/seal/` and do not unzip it (roms/seal/README.txt says so, with the credit: Seal of Flames is by Laz14, GameBanana 656034, CC BY-NC-ND 4.0, not included).
3. Start PLAY.bat, PLAY RANDOMIZED.bat or PLAY SEAL OF FLAMES.bat. All tools find the files through one helper, tools/paths.py.
4. If something is wrong, it stops with one plain sentence: an update or add-on .cia in roms/, a wrong edition, a changed dump, two game files, or no game file.
5. To test without starting anything: `PLAY.bat --check`, `PLAY RANDOMIZED.bat --check`, `PLAY SEAL OF FLAMES.bat status` or `--dry-run`.

## What still uses the old places (for one release)
- If roms/ has no game file, the tools still find it in the repo root and print "please move it to roms\". The same goes for a `Seal of Flames v6` folder in the root.
- play/config.json on your PC still names the old root path. The launchers say in one line that the file is not there and use roms/. The file is never rewritten. You can clear its "rom" line to stop the note; your Zakuro folder setting is untouched.
- play/game/game-path.txt still names the old root path. The bats pass the path on the command line, so they are not affected; only starting the exe directly with no arguments reads it.
