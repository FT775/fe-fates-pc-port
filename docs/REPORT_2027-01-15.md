## 1. Chests and villages (how they will work)
- A chest, a village or a talk gift will give a different item, picked from the seed.
- No game file and no Seal of Flames file is rewritten. Script files and text files are only read.
- The swap happens in memory at the moment the game hands the item over. The game function for that is ev::ItemGain at 0x003B0768.
- With the randomizer off, the original code is put back, so the game is the original.
- **Counts:** Fates has 96 chests, 28 villages and 2 talk gifts. That gives 76 slots we can change in all (a slot is one chapter's item; several chests in one chapter giving the same item share a slot). By path: 20 on Birthright, 21 on Conquest, 35 on Revelation and 6 in paralogues; these add up to more than 76 because the chapters shared by all paths count on each path. Seal of Flames has 61 slots. Seal was read from the installed mod only, and nothing of it is saved in the repo.
- **Rules:**
  - Story and key items never change: Yato and its forms, Ganglari, dragonstones, Missiletainn, keys, and the like.
  - The new item is in the same price band as the old one, like castle rewards.
  - The same item is not given twice in one chapter.
  - The same seed always gives the same items.
- Event gifts and gold stay as they are for now (call C1).
- **Built now:** the list writer, tools/randomizer/chests.py, with 18 tests. It is OFF and not on the page yet.
- **Judge for the robot:** rcheck.judge_chest, with 5 selftest cases. It checks that the item the game gave matches the plan.
- **Still to prove in round 71:** that tile kind 10 means chest and 1 means village.

## 2. The download (what it needs, what blocks it)
- **What it would be:** our Zakuro program with no game inside it. The player's own copy of the game is turned into the game by Zakuro's own Recompile step on their PC.
- **What switches off in that mode:**
  - the game path start (patch 0005);
  - Choose your game and Seal of Flames (0012 and 0013).
  - A later "port mode" patch can bring them back (estimate 1 h 20; not in round 71).
- **Testing:** it would be tested in a sandbox folder under build/.
  - Zig is copied in read-only, so nothing downloads.
  - A before/after snapshot proves your real %APPDATA% and %LOCALAPPDATA% stay unchanged. Two snapshots taken 10 s apart were equal.
- **Python for a PC without it:** the small official Python 3.13 bundle, about 11 MB (estimate). Its licence is fine. Getting it is a download, so it waits for your OK in round 77.
- **What blocks it:**
  1. **3dsrecomp** (recomp3ds and recomp-abi, from github.com/fearkov/3dsrecomp) has no licence file, and it is inside every Zakuro program. Default: source-only until its author says OK. You could ask the author to add a LICENSE file or give a written OK. Claude sends nothing.
  2. **Symphonia** (4 audio packages) is MPL-2.0, which is copyleft. Default: stop until you say MPL is fine.
- **Plan B if the author never answers:** a tools-only download that makes randomized mod folders for the official Zakuro. It has no in-game page, no Nuzlocke, no growth view and no Seal picker.

## 3. Full swap rules
- **Missing faces:** if a swapped character has no face for a scene's expression, the game's own code already falls back to their normal face. No portrait files are painted or written. A seed is refused if the character lacks even the normal face.
- **Voices:** voice lines of swapped characters are muted in the same message hook that swaps names in dialogue. It comes in round 74.
- **The four trouble chapters** (Revelation 8 and 13, Conquest 9 and 16):
  - If one breaks only in dialogue, "full" turns off for that chapter only.
  - If faces, models or menu names break, "full" stays off everywhere, and the page says why.
  - A chapter the robot cannot reach counts as not proven.
- **Presets and share code:** two presets, Light and Wild, plus a separate Share code field. Round 74, 2 h 10 estimate.
