## smoke.py replaces the hand-made smoke scripts
- tools/harness/smoke.py runs the same 8 jobs as rounds 63 to 66: Birthright A011, Conquest B016, Revelation C012 and Seal R011, each with the randomizer off and with everything on. It also runs the memory compare with the randomizer off at boot, frames 3000/4600/5200, and the end.
- It runs headless and muted, and exits by itself, at low priority.
- A window watcher stops everything if a window appears. STOP_ROUND is checked all the time. It uses only frozen copies of the game files, never play/game.
- If an input file is missing or has the wrong checksum, smoke FAILS. It never skips.
- **Proof against round 66:**
  - 8/8 PASS in 103.9 s.
  - Every job has the same verdict, map frame and unit/cell hashes as round 66.
  - Both re-made patches are byte-identical to round 66's.
  - The memory hashes at all 5 points equal round 62b's compare.
  - So the baseline (config/harness/smoke_baseline.json) was written from this run. It is marked NEW and waits for your ok.
- It passed and matched the baseline again in both core passes.
- Honest note: my first launch failed after 17 s on a bug in my own tool, before any of the 8 robot jobs started (only the memory compare ran, and it passed). The one allowed re-launch is the proof.
