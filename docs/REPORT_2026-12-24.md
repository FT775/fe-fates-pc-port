# Randomizer inside the game: where it stands (round 50)

**Short answer: not ready to use yet.** You asked to set every randomizer setting right after picking Casual or Classic in a New Game. That page does not exist in the game yet. Your game program has not changed, and nothing in your game is different today.

## Where the page will be (round 51)
1. Start the game as usual and pick New Game on an empty file.
2. Pick the difficulty, then pick Casual or Classic (or Phoenix).
3. The game pauses and a Randomizer page opens over it.
4. Set the rows, then press Start game. The game goes on to the avatar screen.

Later, Esc, then Randomizer, shows what the current game was started with.

## What each row will do
These are the same rows and defaults as PLAY RANDOMIZED, plus "Everything on".
- Randomizer on/off: off means the original game, untouched.
- Seed: type one or press Random. The same seed gives the same game.
- Classes, Growths, Join stats: a new allowed class, new growth rates and new starting stats for each playable person.
- Growth mode and Bases mode, with their variance, min and max, HP adjust and scale-to-level: how growths and bases are changed.
- Personal skills and Skill slots: shuffle or randomize skills.
- Starting items, Shops, Shop sides, Castle rewards.
- Enemy weapons, Enemy classes, Boss classes, Enemy trees.
- Class trees and Keep royals: limits on which classes can be picked.
- Children: shown greyed out, always off.

## Starting and continuing a randomized game today
Use PLAY RANDOMIZED.bat:
- New game: type 1, give a seed and the switches, and the game starts. Pick New Game in it.
- Continue: type 2 and pick the seed.

After round 51 the in-game page keeps the seed in a small file beside each save. Loading that save brings the same randomized game back. PLAY RANDOMIZED stays as the fallback.
