# Report: how much of the game the robot actually runs

**The number: 8,342 game functions.** That is about half (51%) of the game's 16,312 functions. Two helpers counted in two different ways and I checked them against each other. One watched the game run and marked every function it entered. The other worked it out from the robot's old recordings. The first is the main count. The second added 33 functions from chapters the first did not replay. Library code (Nintendo's SDK, the video decoder, the C library) is left out, as you decided in F-038.

**What it means.** These are the functions we can turn into readable C and still prove correct, because the robot's recordings already run them. The other half stays as the original code for now. 240 of them are already readable, which leaves 8,102 to do.

**The time it implies** (counted, working every day, no new chapters):
- At 2 proven functions a day: about 11 years.
- At 5 a day: about 4.4 years.
- At 10 a day (with helpers): about 2.2 years.
- The 2,487 readers alone, the safe kind that change nothing: about 8 months at 10 a day, or 1.4 years at 5 a day.

**Thumb share: zero.** None of the 8,342 are Thumb code, so this list needs no engine change for Thumb.
